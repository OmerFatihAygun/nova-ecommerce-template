# Third-party licences

Open-source packages used by Nova are **not copied into this zip**. They are downloaded
when you run `npm install` and stay under their own licences.

The full credit list (package, licence, purpose) is in **CREDITS.md**.

Bundled with this package:

* `OFL.txt` — SIL Open Font License 1.1, covering the Inter and Plus Jakarta Sans
  typefaces loaded via `@fontsource/inter` and `@fontsource/plus-jakarta-sans`.

Run `npm ls --all` in `storefront/` or `admin/` after install for the complete tree.
